# NicoKaraPrep（タイムタグツール）

RhythmicaLyrics で作成したタイムタグ付き歌詞を、ニコカラメーカー3 に読み込ませるために加工する Windows アプリです。

## 主な機能

- **ファイル入出力**
  - RhythmicaLyrics 編集ファイル（.rlf）の読み書き（バイナリ形式を完全サポート、RhythmicaLyrics でそのまま開けます）
  - タイムタグ付き lrc（ルビ拡張規格 @RubyX・@Emoji 対応）の読み書き
  - RhythmicaLyrics「テキスト編集モード」形式（チェック数 `[2|00:12:34]`・ルビ `{漢字|かん＋じ}` 付き）のクリップボード貼り付け / コピー
- **@Emoji アイコン挿入**
  - 20 スロットのパレット（キー `1`–`0` / `Q`–`P`、画像プレビュー付き）
  - **絵文字挿入ビュー（F2）**: 歌詞全体を 1 画面に表示し、キーボードだけで作業できる専用ビュー
    - `←→↑↓` でカーソル移動、`1`–`0` / `Q`–`P` でその位置に挿入、`Esc` で終了
    - 再生ショートカット: `A`=再生 `S`=一時停止 `D`=一時停止/再開 `Z`=数秒戻る `X`=数秒進む（秒数は設定可）
    - `F` で**再生追従カーソル**: 再生中、次に歌われる文字の位置へカーソルが自動移動し、そのまま挿入できる
  - 読み込んだ rlf / lrc に `@Emoji=` タグがあれば**パレットへ自動登録**（空きスロットに割り当て）
  - タイムタグ自動付与: 終了時刻 = 直後の実文字のタグ時刻 T、開始時刻 = T − 指定秒数（デフォルト 2 秒）
  - 連続絵文字は「各絵文字ごと」/「ブロックの先頭と末尾のみ」を設定で選択可能
  - リストはグローバル（アプリ共通）＋曲ごと上書きの 2 層。lrc 出力時に使用中の `@Emoji=` タグを自動出力
- **タイムタグ重なりチェック（ページ間行衝突）**
  - 空行（または固定行数）をページ区切りとして解釈し、隣接ページの「下から同じ位置」の行同士の表示時間の重なりを検出
  - 行の表示区間 = 先頭タグ − 表示前秒数 〜 最終タグ + 表示後秒数（ニコカラメーカー側の設定に合わせて変更可）
  - 絵文字の先行タグは計算から除外。パート分け同時歌唱の重なりは ♪ 印の情報表示のみ
- **1 行の横幅チェック（ピクセル実測）**
  - 指定フォント・サイズで DirectWrite 実測し、画面はみ出し（エラー）/ 左右マージン不足（警告、デフォルト各 5%）を判定
- **行操作**: カーソル位置での行分割（Ctrl+Enter）・行結合（Ctrl+J）・空行挿入・行削除
- **行エクスポート（切り出し）**: 選択行を lrc / rlf / クリップボードへ書き出し。エクスポート済み行には ✓ 済マークが付き、未エクスポート行だけを次回まとめて選択できます（済マークは `.tttproj` に保存）
- **メディア再生**: 動画 / 音源を再生しながら編集。再生位置の行を自動ハイライト、行ダブルクリックでシーク（Ctrl+Space 再生/一時停止、Ctrl+←/→ 5 秒シーク）

## ビルド

必要環境: .NET SDK 8 以降（Windows）、Windows 10 1809 以降

```powershell
dotnet test                          # Core の単体テスト
dotnet build src/NicoKaraPrep.App -p:Platform=x64
# 配布用（自己完結型）
dotnet publish src/NicoKaraPrep.App -c Release -r win-x64 -p:Platform=x64 --self-contained -o publish
```

`publish\NicoKaraPrep.exe` を実行します（Windows App SDK ランタイム同梱）。

## 構成

```
src/NicoKaraPrep.Core    データモデル・フォーマット(lrc/rlf/テキスト編集モード)・検証・エクスポート
src/NicoKaraPrep.App     WinUI 3 アプリ本体
tests/                  xUnit テスト（ラウンドトリップ中心）
資料/                    RhythmicaLyrics v64 ソース（フォーマット解析の参照元）
```

## ファイル形式メモ

- **rlf** = HSP プラグイン hspda の `vsave` バイナリ（`hspv` ヘッダ）。`mojitan`（1 文字ずつの歌詞）・`t_jikan`（タグ時刻、10ms 単位）・`t_kazu`（チェック数）・`sakura_yomi`（ルビ）等の変数を名前付きで格納
- **テキスト編集モード形式**: `[チェック数|mm:ss:cc]` / `[チェック数]` / `{親文字|ルビ＋ルビ}` / `$XXXX` エスケープ（`$2759`=`|` `$271A`=`＋` `$2775`=`}` `$25A8`=2連タグ用スペーサー）
- 実ファイル（2014〜2023 年の RhythmicaLyrics 出力）でラウンドトリップ検証済み

## 動作確認のポイント

1. rlf を開く → 保存 → RhythmicaLyrics で開けること
2. lrc をエクスポート → ニコカラメーカー3 に読み込ませて @Emoji / @Ruby が反映されること
3. ページ衝突チェックの表示前後秒数を、ニコカラメーカー3 側の表示設定と合わせること
