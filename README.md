# NicoKaraPrep（タイムタグツール）

RhythmicaLyrics で作成したタイムタグ付き歌詞を、ニコカラメーカー3 に読み込ませるために加工する Windows アプリです。

## 主な機能

- **ファイル入出力**
  - RhythmicaLyrics 編集ファイル（.rlf）の読み書き（バイナリ形式を完全サポート、RhythmicaLyrics でそのまま開けます）
  - タイムタグ付き lrc（ルビ拡張規格 @RubyX・@Emoji 対応）の読み書き
  - RhythmicaLyrics「テキスト編集モード」形式（チェック数 `[2|00:12:34]`・ルビ `{漢字|かん＋じ}` 付き）のクリップボード貼り付け / コピー
- **@Emoji アイコン挿入**
  - 20 スロットのパレット（キー `1`–`0` / `Q`–`P`、画像プレビュー付き）
  - **絵文字挿入ビュー（F2）**: 歌詞全体を 1 画面に表示し、キーボードだけで作業できる専用ビュー
    - `←→↑↓` でカーソル移動、`1`–`0` / `Q`–`P` でその位置に挿入、`B`=プレースホルダ（＿）挿入、`G`=先行タグ挿入（文字なし、直後のタグの指定秒数前）、`Esc` で終了
    - 再生ショートカット: `Space`=再生/一時停止 `D`=カーソル位置から再生 `A`=再生 `S`=一時停止 `Z`=数秒戻る `X`=数秒進む（秒数は設定可）
    - 行操作: `/`=行分割 `\`=行結合（`Shift+\` でスペースを挟んで結合）
    - `F` で**再生追従カーソル**: 再生中、次に歌われる文字の位置へカーソルが自動移動し、そのまま挿入できる
  - 読み込んだ rlf / lrc に `@Emoji=` タグがあれば**パレットへ自動登録**（空きスロットに割り当て）
  - タイムタグ自動付与: 終了時刻 = 直後の実文字のタグ時刻 T、開始時刻 = T − 指定秒数（デフォルト 2 秒）。n3proj の書き出しでは、前のページの同じ段の行と重なる行だけ、ワイプ前の表示時間まで短くする（それより短い指定秒数は縮めない。前の行のワイプ終了に間に合わない組だけさらに短くする。下の「絵文字の分だけ行の表示を遅らせる」）
  - 連続絵文字は「各絵文字ごと」/「ブロックの先頭と末尾のみ」を設定で選択可能
  - 終わりのタイムタグの無い文字のすぐ後ろに入れたときは、その文字の終わりのタグ（次の最初のタイムタグ）を自動で足す（アイコンの後ろが空白なら前にも T を付けた空白を足し、空白の無い所では 2 連タグにする。アイコンの開始タグで前の文字の時刻が巻き戻らないように）
  - リストはグローバル（アプリ共通）＋曲ごと上書きの 2 層。lrc 出力時に使用中の `@Emoji=` タグを自動出力
- **タイムタグ重なりチェック（ページ間行衝突）**
  - 空行（または固定行数）をページ区切りとして解釈し、隣接ページの「下から同じ位置」の行同士の表示時間の重なりを検出
  - 行の表示区間 = 先頭タグ − 表示前秒数 〜 最終タグ + 表示後秒数（ニコカラメーカー側の設定に合わせて変更可）
  - 絵文字の先行タグは計算から除外。パート分け同時歌唱の重なりは ♪ 印の情報表示のみ
- **1 行の横幅チェック（ピクセル実測）**
  - 字幕のプレビューと同じ並べ方（行に当たるニコカラメーカー3 のフォント設定・ページのレイアウト設定）で測り、画面はみ出し（エラー）/ レイアウト設定の左右余白の不足（警告）を判定
- **行操作**: カーソル位置での行分割（Ctrl+Enter）・行結合（Ctrl+J、スペースを挟む結合は Ctrl+Shift+J）・空行挿入・行削除
- **ニコカラメーカー3 プロジェクト（.n3proj）の書き出し**
  - 歌詞（タブごとの lrc）と一緒に、行の表示開始・終了時刻・パート別フォント・レイアウトまで設定済みのプロジェクトを書き出し。ニコカラメーカー3 では開いてプレビュー／出力するだけ
  - 既存の n3proj をベースにしてフォント設定（配色）・レイアウト・タイトル・出力設定を引き継ぎ。NicoKaraPrep 側で作ったフォント設定を上書き／追加
  - **フォント設定ビュー（F3）**: ニコカラメーカー3 のフォント設定を全項目（配色 8 箇所の単色・グラデーション・ミルフィーユ・画像と不透明度、歌詞・ルビ × 漢字・かな・英数の 6 種類のフォント、文字飾り）編集。アプリ共通と、曲ごとに優先される「この曲専用」を持て、編集はすぐに保存・ビューの中で元に戻せる。n3proj とニコカラメーカー3 のテンプレートから取り込み、使用状況と検証も表示。一覧はフォルダと親子の階層で折りたためる。配色パターン（メイン色・ベース色などの役割）で同じ役割の箇所をまとめて編集し、パターンの形と違う配色（入力の間違い）を検証で知らせる。ほかのフォント設定から役割ごとに色をコピー。色を選ぶ欄の横に、使っているメイン色・ベース色・画像の一覧（同じ色は 1 つ。押すとその色）と、最近使った色。2 人以上で歌うところ用の組み合わせのフォント設定（メイン色を並べたミルフィーユ・グラデーション。端の帯を少し広くする）を作り、絵文字を続けて入れたときは自動で作る（一覧で複数のフォント設定を選んで（Ctrl+クリックも可）作ることもできる）。元のメイン色を変えると組み合わせも作り直す。文字と縁の明るさが近い見づらい配色を知らせ、直す色の候補を出す
  - **レイアウト設定ビュー（F4）**: ニコカラメーカー3 のレイアウト設定（上下配置・余白・行間・スマート水平配置・行ごとの左右・文字の間隔・ルビ）を 3 列の画面で編集。一覧に書き出しと同じ並びでベース・編集・新規の印と使っているページ数を出し、追加・複製・削除、ニコカラメーカー3 のレイアウトのテンプレート（TemplateLayout）から取り込み。アプリ共通ですぐに保存し（書き出しでベースの同じ名前に上書き・無い名前は追加）、ビューの中で元に戻せる。全タブのページの一覧（行数・歌い出し・レイアウト・字幕アクション）でページにレイアウトと字幕アクションを指定し、見本で並びを確かめられる
  - **字幕アクション 8 種類**（アクションしない・フェードイン・フェードアウト・フェードイン/アウト・文字単位フェード・スピンフリップ・ユートピア・上下スライド）を、曲の既定（自動ではベースの n3proj でいちばん多いもの → ニコカラメーカー3 の「すべて同じ字幕アクションにする」→ 文字単位フェード）と、ページごと（右のパネル・レイアウト設定ビュー）・行ごと（行設定の欄。複数行をまとめて）の指定で書き出す。n3proj の読み込みで行ごとのアクションも取り込む
  - 行ごとの表示開始・終了時刻とフォント設定名を NicoKaraPrep 上で指定（ページ衝突チェックにも反映）
  - 行リストに、各行に当たるフォント設定（色見本と名前。行の途中で切り替わるときは「→」でつなぐ）を、書き出しと同じ決め方（パート記号・長い名前を優先・次の行へ引き継ぎ。タブはまたがず、タブごとに最初のフォントから。ニコカラメーカー3 と同じ。最初のフォントは書き出し画面でタブごとに選べ、自動ではメインは既定、2 つ目以降は名前に「コーラス」を含むもの）で表示
  - 行リストの歌詞を、ニコカラメーカー3 の歌詞設定パネルのように字幕の見た目（書体・配色・縁・ルビ・アイコン）で描き、文字をクリック・ドラッグで選んで、その文字だけにフォント設定を指定（アイコンが無くても文字単位で色を変えられる）
  - ページごとの文字の大きさ（ニコカラメーカー3 には無い機能。行設定で ±px を指定すると、書き出しで文字の大きさだけを変えたフォント設定「（麻衣）+4」などを作ってそのページに当てる。ルビは同じ割合、縁はそのまま。字幕のプレビューと横幅のチェックにも反映）
  - 行リストの右のパネルに、フォント一覧（押すと選んだ文字・行に指定）と、レイアウト設定・字幕アクションの一覧（押すと、レイアウトは選んだ行のページ、字幕アクションは選んだ行（ページの行すべてにもそろえられる）に指定。今の指定に ✓。レイアウト設定ビューを開くボタン付き）。行リストに各ページのレイアウト、行設定でページごとのレイアウトの指定
  - メディア再生パネルの動画の上に、字幕のプレビュー（書き出しと同じ表示時刻・ページ・レイアウトで、ワイプしながら。近似。スマート水平配置はニコカラメーカー3 の出力で測った規則: 左寄せと右寄せの行があるページだけ、外側の余白をそろえて中央で文字 1 つ分重なるまで寄せる。絵文字は行のタブの @Emoji で描く）を重ねる。再生の操作は動画の下に移して字幕に重ならないように
  - 表示時刻の自動調整（行リストの右のパネル「表示時刻」）: パラメーター（ワイプ前・ワイプ後・表示間隔・最短表示後・重ねてよい・上段を長めに・絵文字の分だけ遅らせる）を決めて「自動調整を実行」すると、全タブの行に表示時刻を持たせる。手で直した行（✎）はそのまま、読み込んだ値・前回の自動調整の値は計算し直す。パラメーターを変えて何度でも実行し直せ、元に戻せる。持たせた表示時刻は、書き出し・字幕のプレビュー・チェックでそのまま使う（歌詞を直しても実行し直すまで変わらない。アイコンの開始が表示開始より前になったら書き出しで縮め、ほかのはみ出しはチェックで知らせる）。行リストの時刻の下の段に各行の表示開始・表示終了を出し（手で指定した値は ✎ と同じ色）、時刻をダブルクリックすると行設定の表示開始・表示終了の欄へ移る
  - 表示時刻の自動計算はニコカラメーカー3 の「自動で表示開始時刻・表示終了時刻を設定」と同じ（実プロジェクトとの照合で確認）。ただし次の「絵文字の分だけ行の表示を遅らせる」が働いた組（遅らせた行と、前のページの同じ段の行の表示終了）は除く
  - 絵文字の分だけ行の表示を遅らせる（ニコカラメーカー3 には無い機能。右のパネル「表示時刻」で切り替え、既定はオン）: アイコン・＿の先行タグが行の歌い出しになって前のページの同じ段の行と重なるときだけ、次の行のワイプ前を本当の歌い出し（アイコン・＿の後ろの文字）から測って行を遅らせ、アイコン・＿の時刻を行の表示開始まで縮めて書き出す（ワイプ前の表示時間まで。表示秒数がそれより短いアイコンは縮めない。それでも重なるときは前の行のワイプ後を削り、前の行のワイプ終了に間に合わない組だけ、前の行をワイプの最後まで見せるためさらに縮める）。歌詞ファイルのタグは変えない。字幕のプレビュー・行設定の説明にも反映し、前の行がワイプの途中で消える行と、アイコンがワイプ前の表示時間（表示秒数がそれより短いアイコンはその秒数）より短くなる行はチェック（表示時刻）で知らせる。ニコカラメーカー3 で表示時刻の自動設定をやり直すと、この調整は消える（縮めたアイコンの時刻は lrc に残る）
  - 同じ段の行を重ねてよい時間（ニコカラメーカー3 には無い機能。右のパネル「表示時刻」の「重ねてよい（秒）」、既定 0 = 重ねない）: 字幕アクションが「文字単位フェード」のときなど、前のページの同じ段の行と重なるときに、前の行のワイプ後や次の行のワイプ前を削るより先に、その時間まで重ねて表示する（行の字幕アクションの種類にかかわらず効く）。ページ衝突チェックはその時間までの重なりを知らせず、字幕のプレビューは重なっているあいだ前の行を薄く・次の行を濃くして描く（近似）
  - レイアウトで画面の位置が違う行（ニコカラメーカー3 には無い機能。右のパネル「表示時刻」で切り替え、既定はオン）: 前後のページの同じ段の行でも、字幕のプレビューで重ならなければ（上寄せ 5 行のページの次の下寄せ 2 行のページ、左寄せ 5 行と右寄せ 5 行のページなど）、表示時刻を詰めず、ページ衝突・表示時刻のチェックでも知らせない（ニコカラメーカー3 は段だけで組にする）
  - 書き出し画面の「適用」で、書き出さずに設定（ベース・タブごとの設定）だけを当てられる
- **ニコカラメーカー3 プロジェクト（.n3proj）の読み込み**
  - ニコカラメーカー3 のプロジェクトを開くと、プロジェクトのメインの歌詞ファイルも一緒に開く（別の歌詞を開いているときは確認）。コーラスなど 2 つ目以降の歌詞設定の歌詞は、自分の歌詞ファイルを持つタブで開く（上書き保存でそれぞれのファイルへ保存）
  - メニュー（読み込み・開く・最近使用したファイル）・ドラッグ＆ドロップ・exe へのドロップ・フォント設定ビューのどこから読んでも同じ確認画面で、取り込む項目（字幕フォントと画面サイズ／実際の表示区間／表示時刻の設定値／表示時刻（全行をそのまま。自動調整は右のパネルで実行）／字幕アクション（いちばん多いものを曲の既定に、違う行だけ行の指定に）／アイコン（@Emoji）／背景素材の動画／書き出しのベース／フォント設定）を選べる
- **行エクスポート（切り出し）**: 選択行を lrc / rlf / クリップボードへ書き出し。エクスポート済み行には ✓ 済マークが付き、未エクスポート行だけを次回まとめて選択できます（済マークは `.tttproj` に保存）
- **メディア再生**: 動画 / 音源を再生しながら編集。再生位置の行を自動ハイライト、行ダブルクリックでシーク（Ctrl+Space 再生/一時停止、Ctrl+←/→ 5 秒シーク）
- **狭い・低い画面（FHD など）**: 動画を右の列（右のパネルの上）に置いて行リストを縦いっぱいに使える（表示メニュー。既定の自動では窓が低いときだけ右の列）。ウィンドウが低いときは動画を自動で縮めて行リストを残し、狭いときは行リストの横幅を 2 段にして歌詞の欄を広く取る。右の列の幅はつまみで変えられ、右のパネルは隠せる
- **MCP（Claude などからの操作）**: MCP クライアント（Claude Code・Claude Desktop など）に `--mcp` 付きで登録すると、起動中のアプリを操作できる（マニュアル 18 章）。ストア版は実行エイリアス `nicokaraprep.exe`（`%LOCALAPPDATA%\Microsoft\WindowsApps`、更新しても同じ）、zip 版は exe の場所で登録する。登録は ファイル > Claude と連携 のボタン 1 つで行える
  - 「Claude Desktop に追加」: 拡張機能のファイル（`nicokaraprep.mcpb`。manifest.json とアイコンだけで、この exe を `--mcp` で起動する）をダウンロード フォルダに作り、Claude Desktop の実行エイリアス `claude-desktop.exe` に渡す（Claude Desktop が「拡張機能をインストールしますか？」を出す。ストア版の Claude Desktop は .mcpb の関連付けを持たないため、ダブルクリックではなく引数で渡す）。入ったかは Claude Desktop の拡張機能のフォルダを読んで確かめ、画面で知らせる
  - 「Claude Code に登録」: claude.exe（PATH・`%USERPROFILE%\.local\bin`・npm・Claude Desktop に入っているもの）を探して `claude mcp add --scope user nicokaraprep -- "exe" --mcp` を実行し（別の exe が登録されていれば消してから）、`~/.claude.json` を読み直して確かめる
  - 手作業の登録（コマンド・Claude Desktop の構成ファイルに書く内容のコピー）は、その画面の「うまくいかないとき」の中
  - 22 の操作: 状態・行の一覧・全文・チェックの読み取り、字幕のプレビューの画像（PNG）、ファイルを開く・n3proj の読み込み・保存・n3proj の書き出し、表示時刻のパラメーターと自動調整、行の表示時刻・フォント（行・文字）・ページのレイアウト・文字の大きさ・字幕アクションの指定と解除、元に戻す・やり直し、行を選ぶ
  - アプリの中の MCP サーバー（公式の C# SDK）が、同じユーザーだけがつながる名前付きパイプで待ち受け、`--mcp` の橋渡し（標準入出力）がクライアントとのあいだを取り次ぐ。アプリが起動していないあいだも橋渡しは応答し（操作には「起動していません」と答える）、起動したあとの操作からつながる
  - 操作はすべて UI スレッドで 1 件ずつ、画面の操作と同じ処理を通す（画面にすぐ出る・1 回の操作は Ctrl+Z 1 回で戻る・ステータスバーに「MCP:」を付けて出す）。ダイアログを開いているあいだは書き込みを断る。ファイル > 設定 で止められる
- **単一インスタンス**: 1 つだけ起動し（ストア版はパッケージごと、zip 版は exe のフォルダごと）、もう一度起動したときや exe へのドロップは、起動中のウィンドウを前に出してそのファイルを開く

## ビルド

必要環境: .NET SDK 8 以降（Windows）、Windows 10 1809 以降

```powershell
dotnet test                          # Core の単体テスト
dotnet build src/NicoKaraPrep.App -p:Platform=x64
# 配布用（自己完結型）
dotnet publish src/NicoKaraPrep.App -c Release -r win-x64 -p:Platform=x64 --self-contained -o publish
```

`publish\NicoKaraPrep.exe` を実行します（Windows App SDK ランタイム同梱）。

検証で起動するときは、利用者の設定を読み書きしないよう、環境変数 `NICOKARAPREP_APPDATA` に作業用のフォルダを入れます（設定と crash.log の置き場所になります）。`--debug-hidden` を付けるとウィンドウを出さずに起動するので、MCP の操作の確認を画面とキーボードを使わずに行えます。

「Claude と連携」の処理は、画面を出さずに `NicoKaraPrep.exe --claude-link status | code | mcpb [フォルダ] | desktop [フォルダ]` で試せます（結果は標準出力に JSON。出力をリダイレクトして使う）。`code` は Claude Code の設定に書き込むので、試すときは環境変数 `CLAUDE_CONFIG_DIR` に作業用のフォルダを入れます（Claude Code の設定ファイル `.claude.json` の置き場所になります）。`desktop` は実際の Claude Desktop にインストールの確認を出します。

### Microsoft Store 提出用 MSIX パッケージ

通常ビルドは非パッケージのまま。`-p:Packaged=true` を付けると MSIX 構成
（フレームワーク依存の Windows App SDK ＋ Store 用マニフェスト）でビルドされる。
MSIX の生成には Visual Studio （または Build Tools）の MSBuild が必要。

```powershell
# 開発者コマンドプロンプト、または MSBuild.exe のフルパスで実行
msbuild src/NicoKaraPrep.App/NicoKaraPrep.App.csproj /restore /p:Configuration=Release /p:Platform=x64   /p:Packaged=true /p:GenerateAppxPackageOnBuild=true
msbuild src/NicoKaraPrep.App/NicoKaraPrep.App.csproj /restore /p:Configuration=Release /p:Platform=ARM64 /p:Packaged=true /p:GenerateAppxPackageOnBuild=true
```

出力: `src\NicoKaraPrep.App\bin\<Platform>\Release\net8.0-windows10.0.19041.0\win-<arch>\AppPackages\` 配下の `.msix`。

提出前のチェックリスト:

1. Partner Center でアプリ名を予約し、「Product identity」の
   `Package/Identity/Name`・`Package/Identity/Publisher` を
   `src/NicoKaraPrep.App/Package.appxmanifest` の `<Identity>` に転記する
   （Visual Studio の［発行 > アプリケーションを Store と関連付ける］でも可）
2. バージョンを上げるときは `Package.appxmanifest` の `Version` を更新
   （第 4 セグメントは Store 予約のため 0 固定）
3. Partner Center の提出画面へ x64 / ARM64 の `.msix` を両方アップロード
   （署名は不要。審査通過後に Microsoft が署名する）

マニフェストには実行エイリアス `nicokaraprep.exe` を宣言している（MCP クライアントに `nicokaraprep.exe --mcp` を登録するため）。ストア版では、MCP の名前付きパイプと単一インスタンスの鍵にパッケージのファミリー名を使う（更新で exe の場所が変わっても同じ）。

ストア版の形をローカルで試すとき（開発者モード）は、作った `.msix` を展開し、`AppxManifest.xml` の `Identity` の Name と呼び出し名を試験用に変えてから `Add-AppxPackage -Register <展開先>\AppxManifest.xml` で登録する（入っているストア版とは別のパッケージになる。終わったら `Remove-AppxPackage` で外す）。展開した中の `AppxBlockMap.xml`・`AppxSignature.p7x`・`[Content_Types].xml` は消しておく。

## ファイル形式メモ

- **rlf** = HSP プラグイン hspda の `vsave` バイナリ（`hspv` ヘッダ）。`mojitan`（1 文字ずつの歌詞）・`t_jikan`（タグ時刻、10ms 単位）・`t_kazu`（チェック数）・`sakura_yomi`（ルビ）等の変数を名前付きで格納
- **テキスト編集モード形式**: `[チェック数|mm:ss:cc]` / `[チェック数]` / `{親文字|ルビ＋ルビ}` / `$XXXX` エスケープ（`$2759`=`|` `$271A`=`＋` `$2775`=`}` `$25A8`=2連タグ用スペーサー）
- 実ファイル（2014〜2023 年の RhythmicaLyrics 出力）でラウンドトリップ検証済み
- **n3proj** = ZIP（エントリ名 `0`）に BOM 付き UTF-8 の JSON 1 つ（ニコカラメーカー3 の ProjectDataModel）。歌詞は `SourceLyricsInfos[].LineInfos` に行種別（0 空行 / 1 歌詞 / 2 ページ区切り / 3 段落区切り）と文字ごとの時刻（同じタグ区間の文字は先頭 `(開始,-1)`・中間 `(-1,-1)`・末尾 `(-1,終了)`、ms 単位）で保存される。文字の `FontIndex` は `LyricsFonts`（フォント設定タブ）のインデックス。実プロジェクトとの照合テストあり（環境変数 `TTT_N3PROJ_SAMPLE` に n3proj を指定。行構成・文字時刻は D:\work 以下の 71 件すべてで一致。表示時刻は Ver 13 系で 100%、Ver 12 系で 8 割強が一致し、残りは手動調整された行）

## 動作確認のポイント

1. rlf を開く → 保存 → RhythmicaLyrics で開けること
2. lrc をエクスポート → ニコカラメーカー3 に読み込ませて @Emoji / @Ruby が反映されること
3. ページ衝突チェックの表示前後秒数を、ニコカラメーカー3 側の表示設定と合わせること
4. n3proj を書き出し → ニコカラメーカー3 で開いて、表示時刻・フォント・レイアウトが設定済みになっていること（歌詞設定パネルで確認）
