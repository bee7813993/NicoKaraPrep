にこぷれっぷ

RhythmicaLyrics で作ったタイムタグ付き歌詞を、ニコカラメーカー3 向けに仕上げる。ニコカラ制作の「下ごしらえ」専用の Windows アプリです。

Windows 10 / 11（64bit）対応・無料／Microsoft Store で配信中

Microsoft Store から入手できます。更新もストア経由で自動的に届きます。

Microsoft Store で入手

インストールせずに使いたい場合は、GitHub Releases の zip を展開して NicoKaraPrep.exe を実行しても同じように使えます。

設定は %APPDATA%\NicoKaraPrep\ に保存され、アプリのフォルダやレジストリは汚しません。

ABOUT THE APP

歌詞ができてからの手作業を、まとめて引き受ける。

タイムタグを打ち終えた歌詞をニコカラにするには、1 行が画面からはみ出していないか確かめて行を分け直し、ページをまたいだ字幕の重なりを潰し、必要ならキャラアイコン（@Emoji）を入れる——という地道な作業が続きます。にこぷれっぷは、その一連の作業をひとつの画面にまとめたツールです。

RhythmicaLyrics の編集ファイル（.rlf）をそのまま読み書きできるので、タグの微調整は今まで通り RhythmicaLyrics で。仕上げだけをこのアプリで行う、という使い分けができます。

FEATURES

行の整形も、アイコン挿入も、切り出しも。

01

キーボードだけで進む挿入ビュー

歌詞全体を 1 画面に表示し、カーソルを動かしてキーひとつでアイコンを挿入。20 個のアイコンが 1–0 / Q–P に並びます。タイムタグは直後の文字から自動計算されるので、再生に合わせて叩く必要はありません。

02

チェックを見ながらの行分割・結合

長すぎる行を分け、短い行をつないで、字幕に収まる形へ整えます。分割・結合するたびに横幅と表示時間が再計算されるので、警告が消えるまでその場で確かめながら作業できます。アイコンを使わない曲でも、ここだけのために使えます。

03

ページ間の重なりチェック

ニコカラメーカーが空行で区切る「字幕ページ」を再現し、前のページの行が消える前に次のページの行が出てしまう箇所を検出します。表示前後の秒数はニコカラメーカー側の設定に合わせられます。

04

1 行の横幅をピクセルで実測

指定したフォント・サイズで実際に描画幅を測り、画面からのはみ出しと左右マージン不足を判定します。アイコンの表示幅（拡大率・縦横比・余白）も計算に含みます。

05

.rlf をそのまま読み書き

RhythmicaLyrics の編集ファイルをバイナリのまま読み書きします。チェック数・ルビ・口パクタグも保持するので、保存したファイルを RhythmicaLyrics で開き直して作業を続けられます。

06

パート分けのための切り出し

選んだ行を別タブへ分離し、パートごとに lrc へ書き出せます。出した行には ✓ が付くので「まだ出していない行」だけをまとめて選ぶことができ、出し忘れ・二重出しを防げます。

WORKFLOW

使う流れ

  1. 歌詞ファイル（.rlf）を開く

    RhythmicaLyrics でタイムタグを打ち終えた .rlf をドラッグ＆ドロップします（タイムタグ付きの .lrc も開けます）。

  2. ニコカラメーカーの設定を取り込む

    この曲用にフォント・画面サイズを決めた .n3proj を読み込みます。同じスタイルで作った別の曲のプロジェクトでも構いません。

  3. メディアを読み込む（任意）

    動画・音源をパネルへドロップすると、再生位置の行が自動でハイライトされ、行をダブルクリックしてその時刻へ飛べます。

  4. チェック結果を見ながら行を整える

    はみ出しやページ間の重なりが一覧に出ます。クリックで該当行へ飛び、行の分割・結合で警告が消えるまで整えます。

  5. 必要ならアイコンを入れる

    パート分けなどでアイコンを使う曲だけ、F2 の挿入ビューでキーを押して入れていきます。このビューでも行の分割・結合ができるので、4 の作業をここで続けても構いません。

    アイコンの定義はアプリ側に持たせられるので、歌詞ファイルを汚さずに済み、前の曲で使ったアイコンをそのまま使い回せます。

  6. 保存して、必要な行を書き出す

    Ctrl+S で rlf のまま保存。パートごとに行を選び、Ctrl+E でニコカラメーカー用の lrc を書き出します。
