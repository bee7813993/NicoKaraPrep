にこぷれっぷ 使い方マニュアル

RhythmicaLyrics で作ったタイムタグ付き歌詞を、ニコカラメーカー3 向けに加工するための Windows アプリです。アイコン（@Emoji）の挿入をキーボードだけで素早く行い、ページ間のタイムタグ重なり・1 行の横幅をチェックしながら行を整え、パート分けなどで行を選んで切り出す——ニコカラ制作の下ごしらえを支援します。フォント設定・レイアウト・字幕アクション・表示時刻まで決めて、ニコカラメーカー3 で「開いてプレビュー・出力するだけ」のプロジェクト（n3proj）として書き出すこともできます。

このマニュアルは版 0.2.0 に合わせています。

1. インストールと起動

Microsoft Store から入手する（おすすめ）

  1. Microsoft Store のページを開き、「入手」でインストールします
  2. スタートメニューの「にこぷれっぷ」から起動します

更新はストア経由で自動的に届きます。

zip 版を使う

インストールせずに使いたいとき（USB メモリに入れて持ち歩くなど）は、こちらでも同じように使えます。

  1. 最新版の zip をダウンロードし、任意の場所へ展開します
  2. NicoKaraPrep.exe をダブルクリックで起動します（インストール作業は不要です）

共通

  • 対応 OS: Windows 10 / 11（64bit）
  • 設定は %APPDATA%\NicoKaraPrep\settings.json に保存されます（アプリフォルダは汚しません）
  • 前回終了時のウィンドウ位置・サイズで起動します
  • にこぷれっぷは 1 つだけ起動します（zip 版は同じフォルダの NicoKaraPrep.exe ごとに 1 つ）。起動中にもう一度起動したり、アイコンへファイルをドロップしたりすると、起動中のウィンドウが前に出て、そのファイルを開きます（保存していない変更があれば、破棄してよいか尋ねます。n3proj は読み込み確認画面、動画・音声はメディア再生で開きます）
  • Claude などの AI から MCP で操作することもできます（18 章）

2. 基本の流れ（クイックスタート）

はじめて使うときの手順です。RhythmicaLyrics でタイムタグを打ち終えた歌詞ファイルと、ニコカラメーカー3 のプロジェクトが手元にある状態から始めます。

1. 歌詞ファイル（.rlf / .lrc）を開く

  • ファイル > 開く...、または画面へドラッグ＆ドロップします。RhythmicaLyrics の編集ファイル .rlf を開くのが基本です（保存も rlf のままなので、RhythmicaLyrics との行き来ができます）
  • タイムタグ付きの .lrc も開けます。RhythmicaLyrics の「テキスト編集モード」のテキストは ファイル > クリップボードから貼り付け（Ctrl+Shift+V）でも読み込めます
  • 2 回目以降は ファイル > 最近使用したファイル からすぐ開けます（読み込んだ n3proj も入ります）

2. ニコカラメーカー3 のプロジェクトを読み込む（推奨）

ファイル > ニコカラメーカー3 プロジェクトを読み込み（n3proj 形式）... で .n3proj を選びます（画面へドラッグ＆ドロップでも可）。確認画面で、画面サイズ・フォント・縁取り・実際の表示区間などの取り込む項目を選べます（5 章）。

  • 取り込むのはこの曲用にフォント・文字サイズ・画面サイズを設定したあとのプロジェクトです。同じスタイルで作る場合は、別の曲で作った n3proj を使い回しても構いません
  • 過去にニコカラメーカー3 で作ったプロジェクトなら、プロジェクトの歌詞も一緒に開けます。手順 1 を飛ばして、いきなり n3proj を開いても構いません
  • n3proj が用意できないときは ファイル > 設定... で画面の横幅・フォント・サイズを直接指定します

3. アイコン（@Emoji）を使う場合はリストを用意する

  • テンプレート > テンプレートを読み込み... で、作品シリーズ用のアイコン一式を適用します（用意してあれば。13 章）
  • 新しく登録するときは 絵文字 > 絵文字リスト編集... で行います（6.1）。「曲専用」のチェックを外しておけばアプリ共通として保存され、別の曲でもそのまま使えます
  • アイコンを使わない曲では、この手順は不要です

4. メディアを読み込む

メディア再生パネルへ動画 / 音源をドロップします。再生位置の行が自動でハイライトされ、字幕プレビューでニコカラメーカー3 での字幕の見え方を動画に重ねて確かめられます（10 章）。

5. 絵文字挿入ビュー（F2）でアイコンを入れる

F2 で絵文字挿入ビューに切り替え、カーソルを動かしてキー 1–0 / Q–P で挿入します（7 章）。「（前奏）」「（間奏 約14秒）」などの定型文も N → 番号で入れられます。

コツ

両手をキーボードに置いたまま、カーソル移動・挿入・行の分割結合・再生を続けて行えます。F で再生追従カーソルを ON にして再生しながら入れても、止めたままカーソルを動かして入れても、結果は同じです（7 章「手の置き方と進め方」）。

6. チェック結果を見ながら直す

画面下のチェック結果に、ページ間のタイムタグ重なり・表示時刻・1 行のはみ出しが出ます。ここを消していくのが主な作業です（9 章）。

  • 結果をクリックすると該当行へジャンプします
  • 長すぎる行は行分割（Ctrl+Enter／挿入ビューでは /）、短い行が続いてページが詰まるときは行結合（Ctrl+J、スペースを挟むなら Ctrl+Shift+J／挿入ビューでは \・Shift+\）で整えます（8 章）
  • アイコンを入れると行が長くなるので、挿入したあとにもう一度横幅を確認してください

7. 保存する

Ctrl+S で上書き保存します（rlf のまま保存され、RhythmicaLyrics でそのまま開けます）。

8. 書き出す

  • ニコカラメーカー3 で仕上げるとき: ファイル > ニコカラメーカー3 プロジェクトを書き出し（n3proj 形式）... で、表示時刻・フォント・レイアウト・字幕アクションまで設定済みのプロジェクトを書き出します（12 章）。フォント設定ビュー（F3）・レイアウト設定ビュー（F4）・字幕アクション・表示時刻の自動調整で、書き出す前に整えておけます
  • 歌詞ファイルだけほしいとき: 必要な行を選択して ファイル > 選択行をファイルへエクスポート（Ctrl+E）で、ニコカラメーカー用の lrc を書き出します（11 章）

3.1 画面が狭い・低いとき（FHD・拡大表示など）

ウィンドウの大きさに合わせて、並べ方が変わります。

  • 表示 > メディア再生の置き場所: 動画を 上の段（横いっぱい）に置くか、右の列（右のパネルの上。行リスト・絵文字挿入ビューを上から下まで使えます）に置くかを選びます。既定の 自動 は、ウィンドウの高さが 1100 より低いとき（FHD（1920×1080）の画面で最大化したときなど）は右の列、高いときは上の段に置きます（ウィンドウの大きさを変えると切り替わります）
  • 右の列に置いたとき: 動画の高さは右の列の幅から決まります（右のパネルの中身が見える高さは残します。絵文字挿入ビューでは、パレットの中身がすべて入るまで動画を縮め、それでも入らない低い画面ではパレットをスクロールできます）。位置のスライダーは動画のすぐ下に、再生ボタン・音量・字幕プレビューはその下の段に並びます
  • 上の段に置いたとき: パネル下端のバーで決めた高さまで使います。ウィンドウが低くて行リストが 3 行ほどしか残らないときは、動画を自動で縮めます（決めた高さは覚えたままで、ウィンドウを広げると戻ります）
  • 右の列の幅: 行リストと右の列の境のつまみを左右にドラッグして変えます（選んで ← → キーでも。ダブルクリックで元の幅）。動画を右に置くときと置かないときで、幅は別々に覚えます
  • 表示 > 右のパネル（フォント・レイアウト／絵文字のパレット）を表示: 外すと右のパネルを隠し、行リスト（絵文字挿入ビュー）を横いっぱいに使います
  • 行リストの列: 歌詞の欄が狭いときは、横幅（px・%）を上下 2 段にし、フォント設定の欄を狭めて歌詞の欄を広く取ります。長い名前は … で切り、マウスを置くと全体が出ます
  • ニコカラメーカー用の行設定: 1 行に並ばないときは、フォント・レイアウトを 2 段目に回します

エンコーディングは自動判別します（Shift-JIS / UTF-8 / UTF-16）。

保存メニューの違い（タブ分離中は特に注意）

ファイルメニューの保存・書き出しの項目には、書くファイルの形式が出ます。上書き保存 と 表示中のタブを上書き保存 は保存先の形式（例: 上書き保存（タブ含む全行・rlf 形式）。まだ保存先が無いときは出ません）、名前を付けて保存 などは選べる形式（lrc / rlf / txt 形式）です。ニコカラメーカー3 のプロジェクトは ファイル > ニコカラメーカー3 プロジェクトを書き出し（n3proj 形式）... で書きます（上書き保存は n3proj を書きません）。

  • 上書き保存（タブ含む全行）（Ctrl+S） … 分離したタブの行も時刻順にマージして元ファイルへ保存します。普段はこれを使えば行を失いません。ニコカラメーカー3 のプロジェクトから開いたコーラスなどの別の歌詞ファイルのタブ（タブにマウスを置くとファイル名が出ます）は、元ファイルにはまとめず、変更があればそれぞれのファイルへ保存します
  • 表示中のタブを上書き保存（Ctrl+Shift+S） … 表示中のタブを前回「別ファイルへ保存」した先へそのまま上書きします（未保存なら保存ダイアログが開きます）。保存先はタブごとに記憶され、.tttproj にも保存されます
  • 表示中のタブを別ファイルへ保存 … いま表示しているタブの行だけを別ファイルに書き出します。デフォルト形式はニコカラメーカー向けの lrc（rlf を開いていても）
  • 表示中のタブへファイルを読み込み（差し替え） … タブ保存した rlf を RhythmicaLyrics でタグ修正して戻ってきたときに、そのタブへ読み込み直します（読み込んだファイルがタブの上書き保存先になります）

自動保存される作業状態（.tttproj）

歌詞ファイルの隣に <ファイル名>.tttproj が自動保存され、次回開いたとき復元されます。

  • エクスポート済みマーク、メディアファイルのパス、パレットの並び順、タブ分離の状態
  • 行ごとの表示時刻・フォント・レイアウト・字幕アクションの指定
  • n3proj 書き出しの設定（ベース・タブごとのレイアウト・曲の既定の字幕アクション）、この曲専用のフォント設定

歌詞ファイル自体には手を加えないので、rlf / lrc はきれいなまま保たれます。

5. ニコカラメーカー3 プロジェクト（n3proj）の読み込み

ニコカラメーカー3 のプロジェクトファイルの読み込みは、次のどの方法でも同じ読み込み確認画面が開き、取り込む項目を選んでから読み込みます。

  • ファイル > ニコカラメーカー3 プロジェクトを読み込み（n3proj 形式）...
  • ファイル > 開く... で .n3proj を選んだとき（歌詞ファイルと同じ画面から選べます）
  • .n3proj を画面（行リストやメディア再生パネル）へドラッグ＆ドロップ
  • .n3proj をにこぷれっぷのアイコンへドラッグ＆ドロップ、または「プログラムから開く」でにこぷれっぷを選んだとき
  • ファイル > 最近使用したファイル で .n3proj を選んだとき
  • フォント設定ビューの 取り込み > n3proj から...（フォント設定だけを選んだ状態で開きます。12.4）

プロジェクトの歌詞も開きます

過去にニコカラメーカー3 で作ったプロジェクトを開くと、確認画面の前に、そのプロジェクトのメインの歌詞ファイル（最初の歌詞設定タブの歌詞ファイル）を開きます（フォント設定ビューの取り込みのときは開きません）。歌詞ファイルはプロジェクトのフォルダからの相対パスで探すので、フォルダごと移したプロジェクトでも開けます。

  • 歌詞を開いていないとき: そのまま開きます
  • 別の歌詞を開いているとき: 「プロジェクトの歌詞も開きますか？」と尋ねます。歌詞も開く（今の歌詞は閉じます）／設定だけ読み込む（今の歌詞にプロジェクトの設定を読み込みます）／キャンセル
  • 同じ曲の歌詞を開いているとき: 尋ねずに、そのまま設定を読み込みます
  • 歌詞ファイルが見つからないときは、開かずに設定だけを読み込みます
  • コーラスなど 2 つ目以降の歌詞設定の歌詞は、それぞれ別のタブで開きます（タブの名前は歌詞設定の名称）。このタブは自分の歌詞ファイルを持ち、上書き保存（Ctrl+S）ではそれぞれのファイルへ保存します。閉じてもメインへは戻しません。次に曲を開いたときも、それぞれのファイルから開き直します

確認画面で選べる項目

確認画面の上部には、プロジェクトの概要（保存したバージョン・画面サイズ・歌詞設定の行数・フォント設定とレイアウトの数）と、開いている歌詞のうち何行がこのプロジェクトの歌詞行と一致したかが表示されます。

フォント設定選んだフォント設定を、にこぷれっぷのアプリ共通のフォント設定（12.4）に取り込みます。配色・6 種類の文字のフォント・文字飾りをすべて取り込みます（同じ名前は置き換え）オフ

読み込んだ内容はステータスバーに表示されます。画面下の 「歌詞ファイルを開いたとき…自動で読み込む」 をオンにしておくと、歌詞ファイルと同じフォルダに n3proj が 1 つだけある場合、開いたときに「字幕フォントと画面サイズ」「実際の表示区間」だけを自動で読み込みます。

ニコカラメーカー側で表示時刻を手直ししたプロジェクトも、「表示時刻」を取り込めばその値のまま見られ、そのまま書き出せます。表示時刻の自動調整を実行すると、読み込んだ値はすべて計算し直します（残したい行は、先に行設定で表示時刻を手で指定してください。12.9）。

6. @Emoji アイコンと定型文

6.1 リスト編集（絵文字 > 絵文字リスト編集）

アイコンの登録・編集はすべてこの画面で行います（パレットの リスト編集... からも開けます）。

  • 行の追加・複製・削除・並び替え（上下ボタン）。上から 20 行にキー 1–0 / Q–P が割り当てられます。21 行目以降もパレットのリストからクリックで挿入できます
  • 文字: 歌詞中でアイコンに置き換える文字列（例 (歩夢)）。複数文字も可。自由に入力できるほか、右の ▼ でフォント設定の名前から選べます（フォント設定と同じ名前にすると、ニコカラメーカー3 の「パート別にフォントを設定」でその記号から先の歌詞がそのフォント設定になります）
  • ワイプ前 / ワイプ後画像: ニコカラメーカーの @Emoji と同じ意味です（ワイプ後は省略可）
  • オプション: NoDecor,Zoom=150,MarginRight=20 のような @Emoji オプション文字列
  • 曲専用: チェックを付けた行はこの曲だけで有効（.tttproj に保存）。外すとアプリ共通（グローバル）
  • 行を選択すると上部にプレビューが表示され、Zoom スライダー・余白・Fix・NoDecor を操作するとオプション文字列が自動生成されます。プレビューは実機とほぼ同じ比率です（アイコン高さ = フォントサイズ × Zoom%）

読み込んだ rlf / lrc に @Emoji= タグが含まれていれば、自動でリストに登録されます。

おすすめの持ち方：歌詞ファイルには @Emoji を入れず、アプリ側で定義する

アイコンは「曲専用」を外してアプリ共通に登録しておくのがおすすめです。歌詞ファイル（rlf）には @Emoji タグが書き込まれないので RhythmicaLyrics 側をきれいに保てますし、次の曲でもそのまま同じアイコンを使えます。作品ごとに一式を切り替えたいときはテンプレート（13 章）に保存しておきます。

ニコカラメーカーが必要とする @Emoji= タグは、lrc を書き出すときに、使用中のアイコンの分がヘッダへ自動で出力されます。

6.2 パレット（右のパネル）

絵文字挿入ビューのとき、右のパネルにパレットが出ます。

  • スロットはキーボードと同じく 10 個ずつ、1–0 の段と Q–P の段に並びます（右の列が狭いときは折り返します）
  • スロットをクリックしてもカーソル位置に挿入できます。ドラッグで並び替えると、キー割り当ても変わります
  • 20 枠に入らなかったアイコンは下のリストに表示され、「キーへ」ボタンで枠へ昇格できます（いっぱいのときは 20 番目のアイコンと入れ替わり）
  • パレット上部に絵文字挿入設定（表示秒数・連続タグ・プレースホルダ文字）が常に表示され、作業中にその場で微調整できます（変更は新しく挿入する分に適用。既存の絵文字へは 絵文字 > 絵文字タイムタグ再計算）
  • 表示秒数の横の 「0秒」トグルで、ワイプしない絵文字用に表示秒数を 0 ⇔ 元の秒数でワンプッシュ切り替えできます

6.3 定型文（「（前奏）」「（間奏 約14秒）」「（後奏）」など）

アイコンではない決まった文字列も、絵文字挿入ビューで入れられます。

  • 入れ方: パレットのいちばん下の 定型文 の一覧を押すか、N のあとに番号（1–0。一覧の左の数字）を押します。N を押すとステータスバーに番号と定型文が出ます（ほかのキーを押すとやめます）
  • 定型文だけのページ: 行頭・行末・空行に入れると、定型文だけの行にして、前後に空行（ページ区切り）を置きます。行の途中に入れたときは、その行の中に入れます
  • 時刻: 定型文だけのページは、前後のページと表示が重ならない時刻にします（画面に出るのは「前のページが消える時刻 ＋ ワイプ前」から「次のページが出る時刻 − ワイプ後」まで）。後奏は曲の終わり（開いているメディアの長さ）まで、前奏は曲の頭（00:00）から表示します。行の途中に入れたときは、直前の文字の終わり 〜 直後の文字の始まりです
    • 例: 歌い終わり 01:12.0・歌い出し 01:26.0・ワイプ前 1.5 秒・ワイプ後 0.5 秒 → 画面に出るのは 01:14.0〜01:24.0、タグは [01:15:50]（間奏）[01:23:50]
  • {秒}: 定型文の中の {秒} は、前後の歌のあいだの秒数（四捨五入）になります。（間奏 約{秒}秒） と登録しておくと、間奏の長さに合わせて （間奏 約14秒） のように入ります
  • フォント設定: 定型文の編集画面の 定型文に使うフォント設定（全部の定型文で同じ。最初は 情報中。空欄なら指定しません）を、定型文に手動指定します
  • 消す: カーソルを定型文の後ろに置いて BS、前に置いて Del でまとめて消せます（定型文だけのページは、足した空行ごと元に戻ります）。Ctrl+Z でも戻せます
  • 登録: 絵文字 > 定型文の編集...（またはパレットの「定型文」の 編集...）で追加・並べ替え・削除します（アプリ共通。上から 10 件に番号 1–0）。最初は （前奏）・（間奏 約{秒}秒）・（後奏） の 3 つが入っています。消してしまった既定の定型文は、編集画面の 既定の定型文を足す で足し直せます。テンプレート（.tttpl）には入りません

6.4 アイコンのタイムタグの仕組み

  • アイコンの終了時刻 = 直後の実文字のタグ時刻 T、開始時刻 = T − 表示秒数（設定「絵文字の表示秒数」、デフォルト 2 秒）
  • 連続するアイコンは設定で「各絵文字それぞれにタグ」（デフォルト）/「ブロックの先頭と末尾のみ」を選べます
  • 終わりのタイムタグの無い文字のすぐ後ろに入れたときは、時刻が巻き戻らないように、その文字の終わりのタグとして T を足します（足したときはステータスバーに出ます）
  • 後から歌詞のタイムタグを修正したら 絵文字 > 絵文字タイムタグ再計算 で、表示中のタブの全アイコン・＿のタグを今の表示秒数で付け直せます（G の先行タグは付け直しません）。アイコン・＿を入れたり消したりしたときも、その行のアイコン・＿はすべて今の表示秒数で付け直します
  • アイコン・＿の先行タグ（T − n 秒）は重なりチェックの計算から除外されます
  • n3proj の書き出しでは、前のページの同じ段の行と重なる行だけ、アイコン・＿の開始時刻を縮めて書き出すことがあります（歌詞のタグは変えません。12.7）

7. 絵文字挿入ビュー（F2）

歌詞全体を 1 画面に表示し、キーボードだけでアイコン挿入・行操作・再生操作ができる専用ビューです。文字の直接入力はできません（誤編集防止）。

下表のキーはデフォルトです。ファイル > キー割り当て（挿入ビュー）...（または挿入ビュー上部の「キー一覧...」ボタン）で、キーボード配列の画面からキー操作の一覧を確認でき、クリックで自由に変更もできます（選んだ機能が別のキーにあった場合は入れ替え。スロットキー 1–0 / Q–P、BS/Del/Esc、方向キー＝カーソル移動、Ctrl 系は固定）。現在の割り当ては挿入ビュー上部の凡例に常に表示されます。

  • 左側に各行の開始→終了時刻と横幅が表示されます（本文とスクロール同期。エクスポート済みの行は ✓ 付き）
    • 時刻はページ衝突チェックと表示時刻のチェック（9 章）の結果で色分けされます（赤 = エラー / オレンジ = 警告）
    • 横幅は「はみ出し = 赤」「左右余白の不足 = オレンジ」に加え、使用率 90% 超でもオレンジで予告表示されます
  • 行情報をクリックすると行を選択できます（クリックでトグル、Shift+クリックで範囲選択）。右クリックで行操作メニュー（タブ分離・既存タブへ移動・エクスポート・済マーク解除・未エクスポート選択）が開き、通常ビューへ戻らずにパート分けとエクスポートまで完結できます
  • 画面下部にカーソル位置の行番号と直前・直後のタイムタグ時刻が表示されます（G で入れた先行タグの確認にも便利です）
  • その上の簡易行エディタに、カーソルの行がタイムタグ付きで出ます。ここで直して Enter か 適用 で反映します（Esc で直す前に戻して挿入ビューへ戻ります）。歌詞の文字やタグを少し直すのに、通常ビューへ戻らずに済みます
  • 行の編集: 行（本文）か左の行情報をダブルクリックするか、簡易行エディタの右の 行の編集... で、その行の歌詞（タイムタグ付き）と 表示開始・表示終了 をまとめて直す画面が開きます。表示開始・終了は mm:ss:cc で入れると手で指定した値、空欄なら自動です。自動に戻す で指定を外します。適用は Ctrl+Z 1 回で戻せます（定型文の表示時間を直すのに便利です）

手の置き方と進め方

このビューは、両手をキーボードに置いたまま作業できるようにキーを配置しています。

  • 右手は基本的にカーソルキー（← → ↑ ↓）に置きます。行の分割・結合をしたいときだけ、そのまま隣の /・\ を押します
  • 左手はキーボードの左側全体に置きます。アイコンのスロットキー 1–0 / Q–P、B N G K、再生操作の A S D Z X はすべてこの範囲にあります
  • 進め方は「カーソルキーで位置を決める → その場でキーを押す」の繰り返しです。アイコン挿入も、行の分割・結合も、同じリズムで進みます

おすすめの使い方: メディアを読み込み、F で追従を ON にして Space で再生。歌に合わせてカーソルが進むので、アイコンを入れたい場所でキーを押すだけで挿入できます。確かめたい所は D でカーソル位置のタイムタグから聴き直せます。

再生に合わせて急いでキーを押す必要はありません

アイコンの挿入位置はカーソルのある場所で決まり、タイムタグは直後の文字のタグから自動で計算されます。RhythmicaLyrics のタイムタグ打ちのように、曲の進行に合わせてリアルタイムでキーを叩く操作ではありません。停止したままカーソルを動かして挿入しても、結果はまったく同じになります。

8. 行の編集（通常ビュー）

ニコカラでは「1 行が画面に収まるか」「ページの切り替わりで前の行と重ならないか」で、行の切り方がそのまま仕上がりに出ます。チェック結果を見ながら行を分けたりつないだりして整えるのが、このアプリの主な作業です。

行リスト

  • クリックで選択、チェックボックスまたは Ctrl+クリックで複数選択。ダブルクリックでその行の時刻へシーク。行を右クリックすると分離・エクスポート等のメニューが出ます
  • 時刻の欄は 2 段です。上の段が歌い出し・歌い終わり（行の最初・最後のタイムタグ）、下の段が表示開始・表示終了（ニコカラメーカーで行を出す・消す時刻。書き出し・字幕のプレビューと同じ値）。手で指定した値は ✎ と同じ色、チェックで問題があれば警告・エラーの色になり、マウスを置くと値の出どころ（自動・読み込み・自動調整・手動）が出ます。時刻をダブルクリックすると、下の行設定の表示開始・表示終了の欄にカーソルが移ります（12.3）
  • 歌詞の欄は、ニコカラメーカー3 の歌詞設定パネルと同じく、字幕の見た目（その文字に当たるフォント設定の書体・ワイプ前の配色・縁・ルビ・アイコン）で暗い背景に描きます。表示 > 行リストの歌詞を字幕の見た目で表示 を外すと、文字のまま表示します
  • フォント設定の欄（歌詞の左）: その行に当たるフォント設定を、色見本（左がワイプ後、右がワイプ前の文字の色）と名前で出します。書き出しと同じ決め方で、行の中にフォント設定と同じ名前の記号（「（麻衣）」など）が出たらそこから先がそのフォント設定になり、次の行にも引き継ぎます。行の途中で切り替わるときは「→」でつなぎます。下の段には、その行のページのレイアウト設定（手動で指定したものには先頭に ✎）が出ます
  • 字幕アクションの欄: その行の字幕アクション（12.6）を出します。手で指定した行は「✎フェードイン」のように強調の色で、指定の無い行は曲の既定の名前を薄い色で出します。マウスを置くと設定値が出ます
  • 文字を選んでフォントを指定: 歌詞の文字をクリックするとその文字を選び（青い背景）、Shift+クリックかドラッグで範囲を広げます。選ぶと行設定のフォントの欄の見出しが「フォント（選んだ N 文字）」になり、そこや右のパネルで選んだフォント設定は選んだ文字だけに指定します。文字の選択は、ほかの行を選ぶか、行リストで Esc を押すと外れます

右のパネル（行リストのとき）

上の切り替えで フォント・レイアウト・字幕アクション を選びます。どれも、行リストで行（文字）を選んでから、一覧の項目を押して指定します。今の指定に ✓ が付き、行リストで Ctrl+Z で戻せます。

  • フォント: 書き出すフォント設定の一覧（色見本つき。名前で絞り込めます）。押すと、選んだ文字（文字を選んでいなければ選んだ行。複数の行も可）にそのフォント設定を指定します。自動に戻す で手動指定をやめます
  • レイアウト: 「（自動）」と、書き出すものと同じレイアウト設定の一覧。押すと、選んだ行のページ（同じページの行すべて）にそのレイアウトを指定します。「（自動）」でページの行数から選ぶのに戻ります。レイアウト設定を編集... で、そのレイアウトを選んだ状態のレイアウト設定ビュー（12.5）を開きます
  • 字幕アクション: 「（既定）」と 8 種類。押すと、選んだ行にそのアクションを指定します。ページの行すべてにそろえる を入れると、選んだ行のページの行すべてに指定します。下に今の曲の既定が出て、曲の既定を設定... で曲の既定（12.6）を選べます

行エディタ・行設定・行プレビュー

  • 行エディタ: 選択行をテキスト編集モード形式（[2|00:12:34] や {漢字|かん＋じ}）のまま直接編集できます。Ctrl+1–0 でアイコン挿入も可能
  • ニコカラメーカー用の行設定: 行エディタの下に、表示開始・表示終了・フォント・字幕アクション・レイアウト・文字の大きさの欄が並びます（12.3）
  • 行プレビュー: 選択行をルビ・アイコン込みの実際の比率で表示します

9. チェック機能

編集のたびに自動で再チェックされます（F5 で即時実行）。結果は画面下の一覧に表示され、クリックで該当行へジャンプします。行リストにも色が付きます。ここに出た警告は、多くの場合 8 章の行の分割・結合や、行設定の表示時刻（12.3）で解消できます。

ページ間のタイムタグ重なり（最重要）

ニコカラメーカーは空行を字幕ページの区切りとして扱います。前のページの行が消える前に、次のページの同じ位置（下から数えて同じ段）の行が出ようとすると、表示が破綻します。このチェックはそれを検出します。

  • 行の表示区間 = 先頭タグ − 表示前秒数（デフォルト 1.5 秒）〜 最終タグ + 表示後秒数（デフォルト 0.5 秒）
  • n3proj を取り込んでいる場合、前ページ側の「実際に消える時刻」はニコカラメーカーの計算値を使います
  • 1 行だけのページは、字幕のプレビューと同じ段で比べます（前のページの下の段の行がまだ出ているあいだに出るときだけ「下から 2 行目」）
  • 前後のページでレイアウトが違い、画面の位置が違う行（字幕のプレビューで重ならない行）は、同じ段でも知らせません（表示時刻の自動調整のチェックボックスで切れます。12.9）
  • 重なり秒数がしきい値（デフォルト 1 秒）を超えるとエラー、以下は警告
  • 表示時刻の自動調整の「重ねてよい（秒）」（12.8）を入れているときは、その秒数までの重なりは知らせません
  • 行内の時刻逆行や隣接行の重なり（パート分け同時歌唱で普通に起きるもの）はエラーにせず ♪ 印の情報表示のみ

表示時刻（n3proj の書き出しと同じ計算）

n3proj の書き出し（12 章）と同じ表示時刻の計算で、前のページの同じ段の行との詰め方を確かめます。

  • エラー: 前のページの行が、ワイプの途中で消えます（表示終了が最終タグより前）。「15行目（ページ3→4・下から1行目）: 前の行（12行目）がワイプの途中（残り 0.3 秒）で消えます」のように、次のページの行を頭に出します
  • 警告: アイコン・＿がワイプ前の時間より短くなる行です（12.7 の計算がオンのとき）。前の行をワイプの最後まで見せるためや、表示時刻の手動指定のためにアイコンが縮む行を、理由と「2.0→1.0 秒」のような秒数で知らせます
  • 警告（行に持たせた表示時刻）: 表示開始が歌い出しより後の行です（ワイプが始まってから行が出ます）
  • エラー（行に持たせた表示時刻）: 表示終了が歌い終わりより前の行です（ワイプの途中で消えます）。値を持たせたあとにタイムタグを直した行などで起きます

1 行の横幅

字幕のプレビューと同じ並べ方で測ります（行に当たるフォント設定・ページのレイアウト設定の文字の間隔を使い、アイコンの表示幅（フォントサイズ × Zoom% × 縦横比 + 余白）も含めます）。画面からのはみ出し（エラー）と、ページのレイアウト設定の左右余白を確保できない（警告）を判定します。行リストに幅 px と、左右余白を除いた幅に対する使用率が表示されます（画面の横幅と左右余白は、幅の欄にマウスを置くと出ます）。フォント設定が当たらない行は、ファイル > 設定 の字幕フォントで測ります。

10. メディア再生と字幕プレビュー

  • メディア再生パネルへ動画 / 音声ファイルをドロップ（または 再生 > メディアを開く...）
  • Ctrl+Space 再生 / 一時停止、Ctrl+← / Ctrl+→ シーク（通常ビュー時。秒数は ファイル > 設定 のシーク秒数）
  • 再生の操作は動画の下にあります（再生・一時停止、再生位置、位置のスライダー、長さ、音量、字幕プレビュー）。動画の上には重ならないので、字幕のプレビューの邪魔になりません
  • 再生位置の行が自動でハイライトされます（再生 > 再生位置に追従してハイライト で OFF 可）
  • パネル下端のバーをドラッグすると高さを変えられます。使わないときは折りたたみ可。表示 > メディア再生の置き場所 で、右のパネルの上にも置けます（3.1）
  • メディアのパスは .tttproj に保存され、次回自動で開きます

字幕プレビュー

字幕プレビューをオンにすると、動画の上に、ニコカラメーカー3 での字幕の見え方を重ねます。

  • 書き出しと同じ表示時刻・ページ・レイアウト・フォント設定で、その時刻のページの行を並べ、タイムタグに合わせてワイプします（ワイプ前・後の配色、縁・影・ぼかし、ルビ、アイコン）。全タブの行を出します
  • 文字の並べ方・行の上下の位置は、ニコカラメーカー3 の出力画像で文字の位置を測って合わせています（スマート水平配置も同じ）
  • 音声だけのファイルは、字幕の画面を暗い色で塗って出します
  • 近似の表示です。フェードなどの字幕アクションは描きません（行ごとのアクションは行リストの字幕アクションの欄で確かめます）。同じ段の行を重ねているあいだ（12.8）は、前の行を薄く・次の行を濃くして描きます

11. タブ分離と部分エクスポート

パート分けなどで「一部の行だけ別ファイルにしたい」ときの機能です。

タブ分離

  1. 行を選択して 選択行を分離（Ctrl+T。タブ横の 選択行を分離 ボタン・右クリック・エクスポート > 選択行を新しいタブへ分離 からも可）→ 新しいタブへ移動します
  2. 入れ忘れた行は 選択行を移動 でタブを選んで追加できます（時刻順に挿入）
  3. タブ名はダブルクリックで変更できます
  4. エクスポート > タブ分離を解除（すべてメインへ戻す） で全行をメインに戻せます（元のページ区切り位置に復元されます。別の歌詞ファイルのタブはそのまま残ります）
  5. タブ構成は .tttproj に保存され、次回復元されます（元ファイルが変更されていた場合は復元されません）

ニコカラメーカー3 のプロジェクト（n3proj）を読み込むと、2 つ目以降の歌詞設定（コーラスなど）の歌詞が別の歌詞ファイルのタブとして開きます（5 章）。分離タブと違い、上書き保存ではそれぞれのファイルへ保存し、閉じてもメインへは戻しません。

エクスポートと済マーク

  • 行を選択して ファイル > 選択行をファイルへエクスポート（Ctrl+E、lrc / rlf / txt。行リストの右クリックでも）または エクスポート > 選択行をクリップボードへエクスポート（テキスト編集モード形式）
  • エクスポートした行には ✓ 済マークが付き、グレー表示になります（元データからは消えません）
  • 未エクスポート行をすべて選択 → 残りをまとめて出力、選択行の済マークを解除 も可能です
  • lrc 出力時は、使用中のアイコンの @Emoji= タグをヘッダへ自動出力します
  • 保存先の初期フォルダは「歌詞ファイルのフォルダ → メディアのフォルダ → 前回保存したフォルダ」の順で選ばれます

12. ニコカラメーカー3 プロジェクト（n3proj）の書き出し

にこぷれっぷで仕上げた歌詞を、ニコカラメーカー3 で「開いてプレビュー・出力するだけ」の状態のプロジェクトとして書き出せます。行ごとの表示開始・終了時刻、フォント（パート別の配色）、レイアウト、字幕アクションまで設定済みになります。

12.1 手順

  1. （推奨）ベースにする既存の .n3proj を用意します。フォント設定（配色・グラデーション）・レイアウト・タイトル・出力設定はベースから引き継がれます。歌詞ファイルと同じフォルダに n3proj が 1 つあれば自動で候補になります
  2. ファイル > ニコカラメーカー3 プロジェクトを書き出し（n3proj 形式）... を選びます
  3. ダイアログで確認・調整して 書き出し... → 保存先を指定します。書き出さずに設定だけを当てるときは 適用 を押します（字幕のプレビュー・行設定・チェックをその設定で作り直します）
    • ベースプロジェクト: 参照 / クリア（クリアすると標準設定で生成します）
    • プロジェクト名、行の既定フォント設定（パート記号が出るまで使うフォント設定名）
    • 行の表示時刻: 表示時刻の自動調整（12.9）で決めます。書き出し画面には、今のパラメーターと、行に持たせた表示時刻の行数が出ます。値を持たない行は、書き出しのときに今のパラメーターで計算します
    • 歌詞設定タブ: メインと分離タブがそれぞれニコカラメーカーの歌詞設定タブになります。レイアウト（行数に応じて自動 / 固定）・最初のフォント（タブの最初の行からパート記号が出るまで使うフォント設定。自動では、メインのタブは行の既定フォント設定、2 つ目以降のタブは名前に「コーラス」を含むフォント設定）・上段の表示（短め / 長め）をタブごとに選べます
  4. 保存先に .n3proj と、歌詞ファイル プロジェクト名.lrc（分離タブは プロジェクト名_タブ名.lrc）が書き出されます。開いている歌詞ファイル自体は上書きしません
  5. ニコカラメーカー3 の「プロジェクトを開く」で書き出した n3proj を開きます

12.2 書き出される内容

項目内容
ページ・段落区切り空行の位置（固定行数モードなら行数ごと）。前後の間隔が「ワイプ前＋ワイプ後＋表示間隔」以上開く箇所は段落区切り
表示開始・終了行に持たせた表示時刻（手で直した値・読み込んだ値・自動調整の値。12.9）があれば、その値のままです。値を持たない行は、ニコカラメーカー3 の「自動で表示開始時刻・表示終了時刻を設定」と同じ計算です（ページ内の行は同時に表示開始、各行は歌い終わり＋ワイプ後で消え、前のページの同じ段の行とは表示間隔を空け、足りなければ詰めます）。これに、にこぷれっぷ独自の計算（12.7・12.8、レイアウトで画面の位置が違う行は詰めない）が加わります
フォント行内に「フォント設定名と同じ文字列」（@Emoji の置き換え文字列など）が出たらそこから先にそのフォント設定を適用し、次の行以降にも維持します（タブごとに最初のフォントから）。「（麻衣）（のりこ）」のように記号が続く箇所は、組み合わせのフォント設定があればそれを使います。行・文字ごとの手動指定があればそれを使います
レイアウトページの行数と同じ行数のレイアウト（2 行のページ → 下寄せ2行 など。ニコカラメーカーの「適用対象レイアウト」の範囲を優先）。タブごとに固定も可。ページに指定したレイアウトがあればそれ。レイアウト設定ビューで編集したレイアウト設定は、ベースの同じ名前のものに上書きし、無い名前は追加します
字幕アクション行ごとの指定があればそれ、無ければ曲の既定（12.6）
背景素材メディア再生パネルの動画（音声のみなら背景色＋音声トラック）。未設定ならベースのまま
@Ruby / @Emojilrc に出力され、ニコカラメーカーが読み込み時に適用

書き出したプロジェクトで、ニコカラメーカー3 の自動設定を実行しないでください

「自動でフォントを設定」は、記号が続く箇所で組み合わせのフォント設定に合ったあとも続く記号ごとに合わせ直すため、そこから先が最後の名前のフォント設定になります。続けて実行する設定（レイアウト・表示時刻・字幕アクション）も、にこぷれっぷが書き出した内容を設定し直します（表示時刻では 12.7・12.8 の調整も消えます）。

書き出した lrc を、名前を付けて保存・表示中のタブを別ファイルへ保存・選択行をファイルへエクスポート で上書きしないでください（縮めたアイコンの時刻が元に戻ります）。歌詞を直したときは、n3proj を書き出し直してください。

12.3 行ごとの表示時刻・フォント・レイアウト・文字の大きさ・字幕アクションの指定（行設定）

通常ビューで行を選ぶと、行エディタの下に ニコカラメーカー用の行設定 が表示されます。

  • 表示開始 / 表示終了: 手で指定する値を mm:ss:cc 形式で入力して Enter（Esc でやめる）。欄に入ると、薄字の今の表示時刻が入るので、そこから直したりコピーしたりできます（変えずに離れれば手動にはなりません）。行リストの時刻をダブルクリックしても、この欄にカーソルが移ります。空欄に戻すと手で指定した値を外します。手で指定した値は、自動調整を実行し直しても変わりません
  • 右側の説明に、値の出どころ（自動・読み込み・自動調整・手動）、ページ番号・画面位置（下から n 行目）、前後ページとの調整の有無が出ます。絵文字の分だけ遅らせた行（12.7）は「絵文字の分だけ遅らせた（絵文字 2.0→1.5 秒）」のように出ます
  • 自動に戻す: 表示開始・終了の値（手で指定した値・読み込んだ値・自動調整の値）を外して、自動の計算に戻します
  • 自動調整...: 表示時刻の自動調整（12.9）のポップアップを開きます
  • フォント: この行に適用するフォント設定名（ベース n3proj とにこぷれっぷのフォント設定から選択。直接入力も可）。横の 編集... で、そのフォント設定を選んだ状態のフォント設定ビュー（12.4）を開きます。空欄のときは、パート記号で自動で決まるフォント設定が薄字で出ます。手動指定をやめるときは、欄を空にして Enter。歌詞の文字を選んでいるときは選んだ文字だけ、行を複数選んでいるときは選んだ行すべてに指定します
  • 字幕アクション: この行の字幕アクション（12.6）を、「（既定）」と 8 種類から選びます。選んだ行だけに指定し、同じページのほかの行は変えません。「（既定）」で曲の既定に戻します
  • レイアウト: この行のページに使うレイアウト設定（ページ単位で、同じページの行すべてに指定します）。「（自動）」でページの行数から選ぶのに戻ります
  • 文字の大きさ（ニコカラメーカー3 には無い機能）: この行のページの文字の大きさを、フォント設定の文字サイズに足す px で指定します（+4 で 4px 大きく、-4 で小さく。0 でそのまま。ページ単位）。ルビは同じ割合で変え、アイコンも文字の大きさに合わせて変わります。書き出しでは、文字の大きさだけを変えたフォント設定（「（麻衣）+4」「標準-2」など）を作ってそのページに当てます
  • 手動指定のある行は行リストに ✎ が付きます。エクスポート > 選択行の表示時刻・フォント指定を解除 で、レイアウト・文字の大きさ・字幕アクションの指定も含めてまとめて解除できます
  • 手動指定は .tttproj に保存され、表示時刻はページ衝突チェックにも反映されます。どれも行リストで Ctrl+Z で戻せます

12.4 フォント設定を作る（フォント設定ビュー・F3）

ニコカラメーカー3 の「フォント設定」タブに相当するフォント設定を、フォント設定ビューで全項目作り・編集できます。

  • 開き方: F3、表示(V) > フォント設定ビュー、メニューバー右の切り替えの フォント設定、エクスポート > ニコカラメーカー3 のフォント設定を編集、行設定のフォント欄の横の 編集...（その行のフォント設定を選んだ状態で開きます）
  • 戻り方: Esc、もう一度 F3、左上の …へ戻る (Esc) ボタン。開く前のビュー（行リストまたは絵文字挿入ビュー）へ戻ります。行の選択・再生状態はそのまま残ります

  • 名前: Enter か欄を離れると確定します。@Emoji の置き換え文字列（例 （花帆））と同じ名前にすると、その記号以降の文字に自動で適用されます。名前を変えると、行ごとのフォント指定と書き出し設定の既定フォントも新しい名前になります
  • 配色: 8 箇所のボタンを押すと、下の欄でその箇所を編集します。塗りの種類は 単色（ColorPicker・16 進・不透明度 %・スポイト。未指定に戻す で書き出し時にベースの色を使います）／グラデーション・ミルフィーユ（マーカーの位置・色・不透明度。均等に配置・端を広く配置 で位置を並べ直せます）／画像（パス・参照...・拡大率 %）。前後を交換・後→前へコピー・前→後へコピー・他のフォントから色をコピー... もあります

  • 使っている色・最近使った色: ColorPicker の右に、フォント設定で使っている色（と画像）が配色パターンの役割ごとに並び、押すとその色にします。その下の 最近使った色 には、指定した色が新しい順に 12 色まで並びます
  • 配色パターン: 配色の 8 箇所を「メイン色」「ベース色」などの役割に分け、同じ役割の箇所を同じ色にそろえます。標準は メイン色の反転（2 色） と ワイプ前後が同じ（3 色） の 2 つ。パターンを使っているフォント設定では、1 箇所の色を変えると同じ役割の箇所もまとめて変わります（「同じ役割（…）の N 箇所をまとめて変える」を外すと 1 箇所だけ）。パターンの編集... で自分のパターンを追加でき（役割は 4 つまで）、新しいフォント設定に使うパターン もここで選びます。パターンはにこぷれっぷの中だけのもので、書き出しには色だけが使われます
  • 組み合わせのフォント設定（2 人以上で歌うところ）: （麻衣）（ポルカ） のように、一緒に歌う人のフォント設定の名前をつなげた名前のフォント設定です。歌詞で記号をその並びで続けて書いたところに当たります
    • 絵文字から自動で作る: 絵文字挿入ビューやパレットで絵文字を 2 種類以上続けて入れると、つなげた名前のフォント設定がまだ無ければ、アプリ共通に自動で作ります
    • 手で作る: 基本の欄の ほかのフォント設定と組み合わせて新しく作る...、または一覧の下の選ぶボタン（か Ctrl+クリック）で組み合わせるフォント設定を順に選んで 組み合わせて作る...

  • ニコカラメーカー3 との連動・書き出し: ベースに同名の設定があればその設定を上書きし（未指定の色はベースの値を維持）、無い名前は追加されます。テンプレートと連動しているフォント設定は、にこぷれっぷで編集すると書き出し時に連動を外します。フォント設定はテンプレート .tttpl には含まれません

12.7 絵文字の分だけ行の表示を遅らせる（ニコカラメーカー3 には無い機能）

行の頭にアイコン・＿があると、その先行タグ（T − 表示秒数。6.4）が行の最初のタイムタグになります。ニコカラメーカー3 の自動計算は、そこからさらにワイプ前の時間だけ早く行を出すので（表示秒数 2 秒・ワイプ前 1.5 秒なら、アイコンの後ろの文字の 3.5 秒前）、前のページの同じ段の行のワイプ後が削られ、ひどいときは前の行がワイプの途中で消えます。

表示時刻の自動調整（12.9）の 前のページの同じ段と重なるときは、絵文字の分だけ行の表示を遅らせる をオンにすると（既定はオン。アプリ共通）、前のページの同じ段の行と重なる行だけ、次のように書き出します。

  • 次の行のワイプ前を、アイコン・＿の後ろの文字（本当の歌い出し）から測ります。次の行は、前の行のワイプ後と表示間隔が残るところまで遅れて出ます（上の例なら最大 2 秒）
  • アイコン・＿の開始時刻は、行の表示開始まで縮めます（終わりの時刻は変えません）。アイコンにはワイプ前の時間を残し（上の例なら 2.0 秒 → 1.5 秒）、それでも重なるときは前の行のワイプ後などを詰めます
  • 前の行のワイプの終わりに間に合わないときは前の行をワイプの最後まで見せることを優先し、アイコンはそれより短くなります（チェックで警告。9 章）。歌い出しが前の行のワイプの終わりより前（掛け合いなど）のときは、どう詰めても前の行はワイプの途中で消えます（チェックでエラー）
  • 重ならない行は、ニコカラメーカー3 と同じ計算のままです。表示開始を手動で指定した行は、表示時刻を動かしません。G で入れた先行タグは歌い出しとして扱います（遅らせません）
  • 縮めるのは、書き出す n3proj と lrc の中のアイコン・＿の時刻だけです。開いている歌詞ファイル（rlf）のタグは変えません

字幕のプレビュー・行設定の右の説明・チェックも、書き出しと同じ計算です。チェックボックスを外すと、どれもニコカラメーカー3 と同じ計算に戻ります。書き出したプロジェクトでニコカラメーカー3 の「自動で表示開始時刻・表示終了時刻を設定」を実行すると、この調整は消えます。

12.8 同じ段の行を重ねる（ニコカラメーカー3 には無い機能）

字幕アクションが「文字単位フェード」のときなどは、前の行が消えきる前に次の行が出ても見づらくないことがあります。表示時刻の自動調整のポップアップの 重ねてよい（秒） に秒数を入れると（アプリ共通。既定は 0 秒で、ニコカラメーカー3 と同じ計算）、前のページの同じ段の行と重なるときに、その時間まで重ねて表示します。

  • 詰めるときは、前の行のワイプ後や次の行のワイプ前を削るより先に重ねます。重ねても足りないときだけ詰めます
  • 例: 前の行のワイプが 22.2 秒に終わり（ワイプ後 0.8 秒で 23.0 秒に消える）、次の行が 22.8 秒に出る組。重ねなければ前の行を 22.725 秒で消しますが、0.5 秒まで重ねてよいなら、前の行は 23.0 秒まで残ります（0.2 秒重なります）
  • 重ならずに済む組は今までどおりで、必要のない重なりは作りません
  • 行の字幕アクションは見ません。フェードの無い「アクションしない」などの行どうしでも重ねるので、字幕アクションを使い分けるときは、見づらくないかを確かめてください
  • ページ衝突チェックは、この時間までの重なりを知らせません。字幕のプレビューでは、重なっているあいだ前の行をだんだん薄く、次の行をだんだん濃くして描きます
  • 12.7 の計算と一緒に使えます。書き出したプロジェクトでニコカラメーカー3 の「自動で表示開始時刻・表示終了時刻を設定」を実行すると、重ねた分は消えます

12.9 表示時刻の自動調整（読み込み → 自動調整 → 手直し → 書き出し）

行の表示時刻は、行ごとに値を持たせられます。値には出どころがあり、行設定の説明（12.3）と、表示時刻の自動調整のポップアップに出ます。

出どころ決まり方自動調整を実行すると
手動行設定の表示開始・終了の欄に入れた値（行リストに ✎）そのまま残す
読み込みn3proj を読み込むとき「表示時刻」を選んだ行（5 章）計算し直す
自動調整ポップアップの 自動調整を実行 で決めた値計算し直す
自動（値なし）書き出し・字幕のプレビュー・チェックのたびに、今のパラメーターで計算する計算して値を持たせる

値を持たせた表示時刻は、書き出し・字幕のプレビュー・チェックでそのまま使います。パラメーターや歌詞を変えても、自動調整を実行し直すまで変わりません。

流れの例

  1. ニコカラメーカー3 のプロジェクトを読み込みます（確認画面の「表示時刻」をオンのまま）。行は、ニコカラメーカー3 で設定されていた表示時刻のまま、字幕のプレビュー・チェックに出ます
  2. 行設定の 自動調整...（または エクスポート > 表示時刻の自動調整...）でポップアップを開き、パラメーターを決めて 自動調整を実行 を押します
  3. 字幕のプレビューやチェックを見ながら、パラメーターを変えて何度でも実行し直せます。Ctrl+Z で 1 回前に戻せます（歌詞設定タブごと）
  4. 直したい行は、行設定の表示開始・終了の欄に値を入れます（手動）。手動の値は、自動調整を実行し直しても変わりません
  5. 字幕のプレビューで確かめて、n3proj を書き出します（12.1）

表示時刻の自動調整（ポップアップ）

  • パラメーター: ワイプ前・ワイプ後・表示間隔・最短表示後（0 は自動）・重ねてよい（12.8）・上段の行をページの最後まで表示する・絵文字の分だけ行の表示を遅らせる（12.7）・レイアウトで画面の位置が違う行は、前後のページの同じ段でも重ならないものとして扱う（ニコカラメーカー3 には無い機能。既定はオン）。アプリ共通の設定で、変えるとすぐに保存します。ニコカラメーカー3 がインストールされていれば、ニコカラメーカーの設定値を取り込む で同じ値にできます
  • 自動調整を実行: 全タブの行の表示時刻を、今のパラメーターで決め直します。手動の値は残し、ほかの行を計算し直して自動調整の値として持たせます。結果はステータスバーに出ます
  • ポップアップの上に、表示中のタブの行数（手で直した行・読み込んだ行・自動調整の行・未設定の行）と、今のパラメーターで実行し直すと変わる行の数が出ます
  • 値を持たない行（新しい曲など）は、パラメーターを変えるとすぐに計算し直します。実行しなくても、そのまま書き出せます
  • 閉じる で閉じます

値を持たせたあとに歌詞を直しても、表示時刻は変わりません。タイムタグが表示時刻からはみ出すと、チェックの「表示時刻」で知らせます（9 章）。直すときは自動調整を実行し直すか、行設定で直します。

16. 困ったとき

  • rlf を保存したのに RhythmicaLyrics で歌詞が表示されない → 本アプリの旧バージョンの不具合です。最新版で開いて保存し直してください
  • アイコンのプレビューと実際の見た目が違う → ファイル > 設定 のフォント・サイズ・縁取りが実際のニコカラメーカー設定と合っているか確認してください（n3proj の読み込みが確実です）
  • 挿入ビューで文字が打てない → 仕様です（誤編集防止）。歌詞の少しの修正は挿入ビューの簡易行エディタ、大きな修正は通常ビューの行エディタか RhythmicaLyrics で行ってください
  • タブが復元されない → 元の歌詞ファイルが外部で変更されると、安全のためタブ構成を破棄します（メインに全行が読み込まれます）
  • lrc を更新したのにニコカラメーカーでルビが出ない・古い読みが出る → ニコカラメーカー3 は歌詞ファイルの「（更新）」再読み込み時にルビの適用結果を使い回すことがあります。歌詞設定で歌詞ファイルを一度消して選び直す（またはニコカラメーカーを再起動する）と正しく反映されます
  • 起動時に「設定ファイルを読み込めなかったため、設定は保存されません」と出る → %APPDATA%\NicoKaraPrep\settings.json が壊れています。絵文字リストなどが既定値で上書きされて消えないよう、この状態では設定を保存しません。壊れたファイルの写しを同じフォルダに settings.json.broken-日時 として残してあるので、settings.json を直すか別の名前に変えてから起動し直してください
  • Claude から操作できない（「にこぷれっぷが起動していません」と答える） → にこぷれっぷを起動しているか、ファイル > 設定 の「MCP サーバーを有効にする」がオンかを確かめてください（ステータスバーの右に「MCP: 待ち受け中」と出ていれば待ち受けています）。zip 版を別のフォルダに展開し直したときは、ファイル > Claude と連携... の状態に「別の場所のにこぷれっぷが登録されています」と出るので、ボタンを押して登録し直してください（18 章）
  • 「Claude Desktop に追加」を押しても「インストールしますか？」が出ない → Claude Desktop を最新にしてから、もう一度押してください。それでも出ないときは、「うまくいかないとき」の「拡張機能のファイルを作って場所を開く」を押し、nicokaraprep.mcpb を Claude Desktop の 設定 → 拡張機能 の画面へドラッグします
  • 「Claude Code に登録」が「Claude Code が見つかりません」と答える → Claude Desktop のチャットで使うときは「Claude Desktop に追加」を押します。Claude Code を使うときは、「うまくいかないとき」のコマンドを使います
  • Claude からの書き込みが「ダイアログが開いている」と断られる → 確認画面・設定・保存の画面などを閉じてから、もう一度頼んでください
  • アプリが落ちた → %APPDATA%\NicoKaraPrep\crash.log を添えてお問い合わせください

18. MCP（Claude などからの操作）

Claude などの AI から、MCP（Model Context Protocol）で起動中のにこぷれっぷを操作できます。「n3proj を読み込んで、ワイプ前 1.5 秒・重ねてよい 0.3 秒で表示時刻を自動調整して、警告の残る行を教えて」「書き出す前に、各ページの字幕の見え方を画像で確かめて」のように頼めます。操作の結果はそのまま画面に出て、元に戻すこともできます。

18.1 つなぎ方（ボタンを押して登録）

  1. にこぷれっぷを起動しておきます（ステータスバーの右に「MCP: 待ち受け中」と出ます）
  2. ファイル > Claude と連携... を開き、使っている Claude のボタンを押します。登録は 1 回だけです（ボタンの下に、今の登録の状態が出ます）
    • Claude Desktop のチャットで使う → 「Claude Desktop に追加」を押します。Claude Desktop に「拡張機能をインストールしますか？」が出るので、「インストール」を押します（「Anthropic によって確認されていません」とも出ますが、にこぷれっぷが作った拡張機能です）
    • Claude Code で使う（Claude Desktop の Code タブも） → 「Claude Code に登録」を押します。このパソコンの Claude Code を探して登録します
  3. Claude の会話から、にこぷれっぷを操作できます。Claude Code は、登録したあとに始めた会話から使えます。Claude がつながると、ステータスバーの印が「MCP: 接続中」になります
  • ファイル > 設定... の「MCP」の欄の「Claude と連携...」からも開けます
  • 拡張機能のファイル（nicokaraprep.mcpb）は、ダウンロード フォルダに作ります。Claude Desktop に入れたあとは消してかまいません
  • ストア版は、更新しても登録し直す必要はありません。zip 版は、その NicoKaraPrep.exe の場所で登録します。新しい版を同じフォルダに上書きすればそのまま使え、別のフォルダに展開したときは登録し直します
  • 止めるときは、ファイル > 設定 の「MCP サーバーを有効にする」を外します

うまくいかないとき

「Claude と連携」の画面の うまくいかないとき（手作業で登録する） を開きます。Claude Desktop は、拡張機能のファイルを作って場所を開く で出てきた nicokaraprep.mcpb を、Claude Desktop の 設定 → 拡張機能 の画面へドラッグします。Claude Code は、表示されたコマンドを コピー して PowerShell かコマンドプロンプトに貼り付けて実行します（ストア版は nicokaraprep.exe という呼び出し名で登録します）。

18.3 決まりごと

  • つながるのは同じ PC の同じ Windows ユーザーのプログラムだけです（ネットワークには出ません）
  • 操作できるのは、にこぷれっぷを起動しているあいだだけです。起動していないときに頼むと「起動していません」と答え、起動したあとの操作からつながります（Claude を起動し直す必要はありません）
  • 書き込みは画面の操作と同じ処理を通り、画面にすぐ出ます。1 回の操作は Ctrl+Z 1 回で元に戻せます。ステータスバーには「MCP:」を付けて出します
  • 行番号は行リストと同じく 1 から数えます（空行も数えます）。タブを指定すると、画面もそのタブに切り替わります
  • 時刻は行リストと同じ mm:ss:cc で受け渡しします
  • 確認画面などのダイアログを開いているあいだは、書き込みを断ります（閉じてから、もう一度頼みます）
  • 歌詞を変える操作は、フォント設定ビュー・レイアウト設定ビューを開いていれば、元のビューへ戻ってから行います
  • 保存していない変更があるときに別のファイルを開く操作は、変更を捨ててよいかを AI が確かめてからでないと行いません
  • 保存・書き出しの先は、フルパスで、フォルダがある場所だけです
