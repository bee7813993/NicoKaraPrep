にこぷれっぷ プライバシーポリシー

最終更新日: 2026年10月8日

← にこぷれっぷ の紹介ページへ

本ポリシーは、Windows アプリ「にこぷれっぷ」(以下「本アプリ」)における利用者情報の取り扱いについて定めるものです。

1. 収集する情報

本アプリは、利用者の個人情報を一切収集しません。氏名・メールアドレス・住所・電話番号などの個人を特定できる情報、および利用状況の統計情報(テレメトリ)を取得することはありません。

2. インターネット通信

本アプリはインターネット通信を行いません。外部のサーバーへ情報を送信することはなく、広告の配信も行いません。

3. AI アシスタントとの連携（MCP）

本アプリには、Claude などの AI アシスタントのアプリ(MCP クライアント)から、起動中の本アプリを操作できるようにする機能があります。

  • AI アシスタントのアプリが本アプリを操作できるのは、利用者が「ファイル > Claude と連携」などで、そのアプリに本アプリを登録したときだけです
  • 本アプリと AI アシスタントのアプリとのやり取りは、同じパソコンの中で、同じ Windows ユーザーのアプリとのあいだだけで行われます(名前付きパイプ)。本アプリ自身がインターネットへ接続することはありません
  • 連携しているあいだ、AI アシスタントのアプリは、本アプリで開いている歌詞・設定の内容や字幕のプレビュー画像を読み取り、本アプリを操作できます。AI アシスタントのアプリがそれらの情報をどのように扱うか(提供元のサーバーへ送るかどうかなど)は、そのアプリと提供元のプライバシーポリシーに従います
  • 「Claude と連携」で登録するとき、本アプリは利用者のパソコンの中で、Claude Code の設定への登録と、Claude Desktop の拡張機能のファイル(nicokaraprep.mcpb)のダウンロード フォルダへの作成を行います。開発者や第三者へ情報を送ることはありません
  • 連携の待ち受けは「ファイル > 設定」の「MCP サーバーを有効にする」で止められます。登録は Claude 側でいつでも解除できます

4. 利用者が扱うデータの保存場所

本アプリが読み書きするデータは、すべて利用者のパソコン内でのみ処理されます。

  • 歌詞ファイル(.rlf / .lrc など)、プロジェクトファイル、画像・音声・動画ファイルは、利用者が指定した場所にのみ保存されます
  • アプリの設定(フォント設定、キー割り当て、アイコンの登録内容、最近使ったファイルの一覧など)は、利用者のパソコン内のアプリ専用領域に保存されます
  • これらのデータが開発者や第三者に送信されることはありません

5. 第三者への提供

前述のとおり本アプリは情報を収集しないため、第三者への提供・販売・共有は一切行いません。

6. 権限について

本アプリは、Microsoft Store で配布されるデスクトップアプリとして runFullTrust 機能を宣言しています。これは Windows のデスクトップアプリを MSIX 形式でパッケージ化する際に必須となる宣言であり、本アプリでは利用者が選択したファイルの読み書き、文字幅の計測、ローカルの音声・動画ファイルの再生といった通常のデスクトップ機能のためにのみ使用します。

また、AI アシスタントのアプリに本アプリを登録できるよう、実行エイリアス nicokaraprep.exe を宣言しています。これは本アプリを呼び出すための名前で、通信や情報の収集には使いません。

7. 子どものプライバシー

本アプリは情報を収集しないため、年齢を問わず、利用者から個人情報を取得することはありません。

8. 本ポリシーの変更

本ポリシーの内容を変更する場合は、本ページを更新し、最終更新日を改めます。

Privacy Policy (English summary)

NicoKaraPrep ("Nicopurepu") does not collect, store, or transmit any personal information. The app does not connect to the internet, contains no advertising or analytics, and does not share any data with the developer or third parties. All files and settings remain on the user's own PC. The runFullTrust capability is declared because it is required for packaged Windows desktop applications; it is used only for ordinary desktop functionality such as reading and writing user-selected files, measuring text width, and playing local media files. The app can optionally be controlled by AI assistant apps such as Claude (MCP clients), but only after the user registers it with them (File > Link with Claude). The connection stays on the same PC and the same Windows user account (a local named pipe); the app itself never connects to the internet. While connected, the AI assistant app can read the open lyrics, settings and subtitle preview images and operate the app; how that app handles the data is governed by its own privacy policy. The app execution alias nicokaraprep.exe is declared only so that the app can be registered with such clients. Contact: bee7813993@gmail.com
