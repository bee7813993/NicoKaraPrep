## 変更点

アプリのマニュアル（`マニュアル.md`）の同じ箇所に合わせたものです。

1. **7 章 絵文字挿入ビュー**
   - メニューの名前を「ファイル > キー割り当て（挿入ビュー）...」から「ファイル > キー割り当て...」に直します。
   - その下に「行リストと同じキー」の段落を足します。Ctrl の付くキーはどちらのビューでも同じ意味、再生の操作の 1 文字のキー（Space・D・A・S・Z・X・F）は行リストでも文字の入力欄の外なら効く、挿入・行分割・結合の 1 文字のキーは挿入ビューだけ、K（空白）と Ctrl+K（空行）は別の操作、という内容です。
   - キーの表: K の行に「空行の挿入は Ctrl+K」を、/ と \ の行に「編集メニューの同じ項目も同じ」を足し、Ctrl+Space / Ctrl+← / Ctrl+→、Ctrl+Enter / Ctrl+J、Ctrl+K（カーソルのある行の下に空行）、Ctrl+Delete（左の行情報で選んだ行を削除）の行を足します。
2. **8 章 行の分割・結合の表**: 挿入ビューの列に Ctrl のキーを足し、「—」だった空行の挿入・選択行の削除を Ctrl+K・Ctrl+Delete にします（挿入ビューではカーソルのある行の下・左の行情報で選んだ行）。表の下に 2 項目を足します。
   - Ctrl のキーはどちらのビューでも同じで、挿入ビューでは編集メニューの表示にも /・＼・Shift+＼ が並ぶこと。
   - 通常ビューの行分割は行エディタのカーソル位置で分けるので、メニューから分けるときは先に行エディタで位置をクリックすること（行の先頭では分けず、ステータスバーで知らせる）。挿入ビューでは編集メニューからでもカーソル位置で分けること。
3. **10 章 メディア再生**
   - 「Ctrl+Space 再生 / 一時停止、Ctrl+← / Ctrl+→ シーク（通常ビュー時）」を、Space・Z / X・D・A / S も含めた説明に直し、行リストでも絵文字挿入ビューでも同じキーであることを書きます。
   - 行リストの 1 文字のキーが文字の入力欄・コンボボックスでは効かないこと、ボタン・チェックボックスの Space はそのボタンを押すことの項目を足します。
   - 再生位置のハイライトの項目を、スクロールの入／切（再生メニューか F）の説明に直します。
4. **17 章 ショートカット一覧**
   - 「どこでも」の表: 行分割・結合と空行挿入・選択行削除に挿入ビューでの動きを添え、「シーク」を「数秒戻る / 進む」にします。
   - 「行リストと絵文字挿入ビュー（文字の入力欄の外）」の表を足します（Space・D・A / S・Z / X・F）。
   - 「絵文字挿入ビュー」の表から再生の操作の行を外して上の表に任せ、K と / \ の行に Ctrl のキーを添えます。

## 反映したあとに確かめること

- 公開中の manual.html に「行リストと同じキー」「行リストと絵文字挿入ビュー（文字の入力欄の外）」の文字があり、「キー割り当て（挿入ビュー）」の文字が無いこと
- 8 章の行の分割・結合の表に「—」が残っていないこと
- 7 章・17 章の表が横にはみ出さず、スマートフォンの幅でも横にスクロールして読めること
