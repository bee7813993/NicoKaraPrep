## 当て方

ykrmoe_web のリポジトリのルートで当てます。

```
git apply <このリポジトリ>/web/site-updates/pr14-manual.patch
```

当たらないとき（サイト側で manual.html を直したあとなど）は、下の「変更点」の 1 か所を手で直してください。

## 変更点

アプリのマニュアル（`マニュアル.md` の 12.4「色の分け方」）に合わせたものです。

1. **12.4 フォント設定ビュー**の「組み合わせのフォント設定（2 人以上で歌うところ）」の中の「メイン色の箇所だけを、…」の項目を書き換えます。
   - 「メイン色の箇所だけを」を「メイン色の箇所を」にします。
   - ベース色なども、元のフォント設定で色が違えばメイン色と同じ帯で分けること（色がそろっていれば、いちばん上の元のフォント設定と同じ）を足します。
   - この分け方より前に作った組み合わせは、作り直すまで前の分け方のままであることを足します。

## 反映したあとに確かめること

- 公開中の manual.html の 12.4 に「ベース色なども、元のフォント設定で色が違えば」の文字があり、「メイン色の箇所だけを」が無いこと
- 組み合わせのフォント設定の箇条書きの入れ子（絵文字から自動で作る・手で作る・…）の並びが崩れていないこと
